# 점 잇기 상자 따기 🔲

점 사이에 번갈아 선을 긋고, 네모의 마지막 변을 그으면 그 네모는 내 땅이 되고 한 번 더 두는 게임입니다. 컴퓨터와 겨룹니다(온라인 대전은 아직 없음). 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: 선 근처를 누르거나(PC 는 마우스를 올리면 밝아짐) 손을 떼면 그어집니다. **무르기**(`Z`)는 내 마지막 차례를 통째로 되돌립니다. `M` 소리.
- 판 크기 3×3·4×4·5×5, 컴퓨터 쉬움·보통·어려움. 이긴 횟수는 `dotsboxesWins`, 단계별 전적은 `dotsboxesRecord`.
- 컴퓨터: 쉬움은 가끔 땅을 못 가져가고 아무 선이나 긋고, 보통은 땅을 가져가고 세 번째 변을 피하며 어쩔 수 없을 땐 가장 적게 내주고, 어려움은 남은 선이 16개 이하가 되면 끝까지 계산(`makeSolver`)합니다.
- `logic.js` 규칙·컴퓨터(`LOGIC_DOTS`), `game.js` 화면·입력·소리, `test/logic.test.js` (`node --test`).

## 균형 (컴퓨터끼리 20판씩, 선공·후공 번갈아)
| 판 | 보통 ← 쉬움 | 어려움 ← 보통 | 어려움 ← 쉬움 |
|---|---|---|---|
| 3×3 | 90% | 98% | 100% |
| 4×4 | 98% | 90% | 100% |
| 5×5 | 100% | 75% | 100% |

가장 느린 컴퓨터의 한 수는 약 17ms (5×5 어려움 끝판 풀이). 5×5 에서 어려움이 보통을 덜 이기는 것은 초반(선이 많이 남은 구간)을 계산하지 않기 때문입니다.

## 연패 구제

보통·어려움에서 3번 연속 지면 「쉬움으로 해 볼까요?」 안내가 뜹니다(`arcade/public/assist.js`). 결과 화면에도 난이도 단추가 있습니다.
